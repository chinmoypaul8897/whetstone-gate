## INC-NN - the probe-fails-on-old-code check reported PASS because the editable

**Event:** To meet hard rule 6's "provably meaningful" bar I cloned the repo to

the repository and was not carried into the verification procedure.

**Diagnosis:** An editable install registers a MetaPathFinder that resolves the
package by name regardless of the working directory, so checking out an old
