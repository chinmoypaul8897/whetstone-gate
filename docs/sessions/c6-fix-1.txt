a reviewer can recompute an episode's offers by hand, and a probe recomputes them
independently:

  corpora = corpora_in_order(entries)          # distinct names, FIRST-APPEARANCE order
  c       = turn_index %  len(corpora)         # WHICH corpus this turn offers
  k       = turn_index // len(corpora)         # the k-th offer from that corpus
  group   = [e for e in entries if e.corpus == corpora[c]]      # in load order
  stride  = max(1, turn_budget // len(corpora))
  within  = (episode_seed * stride + k) % len(group)
